# 坦克大战 · Tank Battle

一个用原生 HTML + Canvas + JavaScript 编写的经典「坦克大战」（Battle City 风格）网页游戏。单文件实现，无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- 控制你的坦克消灭所有敌军坦克，同时**守住画面底部的金色基地**。
- 基地被摧毁或生命耗尽即失败；通关所有关卡即胜利。
- 地图上有两种墙体：
  - 🧱 **砖墙** —— 可被子弹摧毁
  - ⛓️ **钢墙** —— 无法摧毁

## 操作

| 按键 | 动作 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `Space` / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始游戏 |

触屏设备会自动显示虚拟方向键与开火按钮。

## 特性

- 3 张关卡地图，逐关难度递增
- 敌军 AI（转向、瞄准玩家、随机开火）
- 可摧毁砖墙 / 不可摧毁钢墙
- 基地守护机制（己方子弹也会误伤基地）
- 粒子爆炸特效、屏幕震动、音效（Web Audio）
- 得分 / 最高分（localStorage 持久化）/ 生命 / 关卡 / 剩余敌人数 HUD
- 响应式布局与移动端触控

## 运行

直接用浏览器打开 `index.html`，或起一个本地静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
